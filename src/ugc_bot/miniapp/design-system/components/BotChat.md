# BotChat

Окно переписки с ботом - иллюстрация того, как работает сервис.

- `umc-chat` с тенью `shadow-float`: шапка (`__ava` - логотип на белом круге, `__name` с подписью «бот · онлайн»), лента `__thread`.
- Сообщения: `__msg` - ответ UMC (`card`), `__msg--out` - задача клиента (`ink`), `__msg--hit` - новый отклик (`mint`). У каждого жирная подпись `b`.
- Это макет, а не интерфейс: на сайте он `aria-hidden`. В Mini App вместо него - настоящий список откликов.
