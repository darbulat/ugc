# Chip

Чипсы для перечней и цветные статусы.

- `umc-chips` > `li.umc-chip` - ниши, площадки, города; фон `card`. Для выбора в форме используйте их как кнопки с `aria-pressed`.
- `umc-pill` - статус: `--new` «Новый» (`lavender`), `--wait` «В работе» (`peach`), `--ok` «Готово», «Вышла» (`mint`).
- Статус всегда подписан словом: цвет только помогает, различать по одному цвету нельзя.

Что передать: подпись; для статуса - его вид.
