# Tabs

Вкладки-таблетки для переключения форматов или разделов внутри экрана.

- Контейнер `umc-tabs` с `role="tablist"`, каждая вкладка - `button.umc-tab` с `role="tab"` и `aria-selected`.
- Выбранная - заливка `ink`, остальные - `card`. Подписи короткие, одно-два слова: «Автоподбор», «Под ключ», «Регулярный поиск».
- Не больше пяти вкладок; на узком экране они переносятся на вторую строку, горизонтальный скролл не нужен.
- В Mini App при переключении вызывайте `HapticFeedback.selectionChanged()`.

Что передать: список вкладок, выбранную, обработчик смены; панели связываются через `aria-controls`.
