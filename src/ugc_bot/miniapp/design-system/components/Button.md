# Button

Кнопка действия: главная, вторичная и инверсная для тёмного блока.

- `umc-btn umc-btn--primary` - одно главное действие на экран («Запустить подбор»). Заливка `ink`, текст `on-ink`.
- `umc-btn--ghost` - второе действие («Я блогер - хочу задания»). На пастели становится белой без рамки.
- `umc-btn--inverse` и `umc-btn--inverse-ghost` - только внутри `umc-final` (заливка `ink`).
- Размеры: `--lg` 56px для финального блока, обычная 50px, `--sm` 40px для шапки. `--block` растягивает на ширину на телефоне.
- Текст начинается с глагола. В Mini App главное действие - системная MainButton с теми же цветами.

Что передать: текст, ссылку или обработчик, при загрузке - `disabled`.
