# Hero

Первый экран раздела: пастельная заливка, заголовок капсом, пиксельный край снизу.

- `section.umc-hero` (по умолчанию `lavender`), для раздела - `--peach`, `--lilac`, `--mint`. Шапка экрана - того же цвета.
- Внутри: `__kicker` (надпись капсом с чертой), `h1.umc-display.umc-hero__title`, `__lead`, `__cta` с кнопками, `__hint` с короткими фактами через «·».
- Пиксельный край - `::after` с маской из `bundle.css`, перекрашивается в `bg` и работает в обеих темах.
- Один на экран. В Mini App - компактный: отступ сверху `space-24`, заголовок `display-l`.

Что передать: надпись, заголовок, лид, 1-2 кнопки, подсказку.
