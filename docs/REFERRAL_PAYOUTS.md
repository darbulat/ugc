# Реферальные выплаты

## Процесс

1. Пользователь нажимает «Выплатить» в боте (/referral). Созётся заявка (PENDING) с суммой = текущий баланс на момент нажатия.
2. Уведомление уходит в чат поддержки (если задан `REFERRAL_SUPPORT_CHAT_ID`).
3. В админке (Заявки на вывод) оператор меняет статус на **Выплачено** (PAID) после фактической выплаты.

## Правила в админке

- **Статус**: при смене на PAID заявка учитывается в «Выплачено» у пользователя; при отмене (CANCELLED) — не учитывается.
- **Сумма**: при сохранении заявки со статусом PAID в статистике реферера используется именно это значение `amount`. Менять сумму имеет смысл только если фактически выплачена другая сумма (например, округление). После смены суммы баланс пользователя (доход − выплачено) пересчитывается по новым данным.
- Одна заявка на вывод в день на пользователя (при повторной попытке в тот же день бот покажет сообщение «Вы уже подавали заявку на вывод сегодня»).
