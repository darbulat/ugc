# Экспорт диалогов бота (что пишет бот пользователю)

Документ для заказчика: все тексты, которые бот отправляет пользователям — сообщения, кнопки, подсказки. Используйте для просмотра существующих диалогов и добавления новых сценариев.

---

## 1. Старт и выбор роли

### Сообщения
- **Приветствие (/start):**  
  `UMC — сервис для UGC. Бизнесу — подбор креаторов, креаторам — заказы.`
- **Поддержка (/support или кнопка):**  
  `Служба поддержки: @usemycontent. Обращайтесь по любым вопросам!`

### Кнопки выбора роли
- `Я креатор`
- `Мне нужны UGC‑креаторы`
- `💬 Поддержка`
- `Смена роли`

---

## 2. Регистрация рекламодателя

### Вход в сценарий
- **Если профиля нет:**  
  `Вы выбрали роль «Мне нужны UGC‑креаторы». Давайте создадим профиль, чтобы вы могли размещать заказы.`
- **Если профиль есть:**  
  `Выберите действие:`
- **Кнопка:** `Начать`

### Шаги диалога
| Шаг | Что пишет бот |
|-----|----------------|
| Имя | `Как вас зовут?` |
| Телефон | `Укажите номер телефона для связи по заказу. Нажмите кнопку ниже или введите номер вручную (пример: 89001110777).` |
| Город | `Из какого вы города? Пример: Казань / Москва / Санкт‑Петербург` |
| Бренд | `Название вашего бренда / компании / бизнеса:` |
| Деятельность | `Чем занимается ваша компания?` |
| Сайт | `Ссылка на сайт, продукт или соцсети бренда:` |
| Согласия | Текст с ссылками: Оферта, Политика конфиденциальности, Согласие на обработку ПД. Интро по умолчанию: «Профиль создан. Ознакомьтесь с документами и подтвердите.» Для заказа: `Пожалуйста, подтвердите согласие с документами платформы.` |

### Кнопки
- `📱 Поделиться номером телефона`
- `✅ Подтвердить согласие`

### После регистрации
- `Теперь вы можете разместить заказ и найти UGC-креаторов.`
- **Прервана регистрация:**  
  `Регистрация прервана. Чтобы завершить, откройте «Мой профиль» и подтвердите согласие.`

### Ошибки / ограничения
- `Пользователь не найден. Начните с /start.`
- `Заблокированные пользователи не могут регистрироваться.`
- `Пользователи на паузе не могут регистрироваться.`
- `Сессия истекла. Начните заново.`

## 3. Регистрация креатора (блогера)

### Вход в сценарий
- **Если профиля нет:**  
  `Ты — UGC‑креатор. После регистрации бренды смогут находить тебя и отправлять предложения.`
- **Если профиль есть:**  
  `Выберите действие:`
- **Кнопка:** `Создать профиль`

### Шаги диалога
| Шаг | Что пишет бот |
|-----|----------------|
| Имя | `Введите ваше имя:` |
| Instagram | `Прикрепите ссылку на инстаграмм в формате instagram.com/name` |
| Город | `Из какого вы города?` |
| Пол | `Укажите ваш пол:` → кнопки Мужской / Женский |
| Тематики | `О чём ваш контент? Напишите 1–3 тематики через запятую: бизнес, инвестиции, фитнес, питание, бьюти, уход за кожей, путешествия, еда, рестораны, мода, стиль, дети, семья, технологии, гаджеты, лайфстайл, другое` |
| Аудитория — пол | `Кто в основном смотрит ваш контент? По наблюдениям или статистике` → 👩 В основном женщины / 👨 В основном мужчины / 👥 Примерно поровну |
| Аудитория — возраст | `Основной возраст вашей аудитории?` → до 18, 18–24, 25–34, 35–44, 45+ |
| Аудитория — гео | `Где находится основная аудитория? Укажите до 3 городов через запятую: Москва, Казань, Санкт‑Петербург` |
| Цена | `Сколько стоит 1 UGC‑видео? Укажите цену в рублях: 500, 1000, 2000` |
| Бартер | `Иногда вы готовы работать с брендами по бартеру?` → Да / Нет |
| Формат работы | `Помимо UGC, как ещё вы готовы работать с брендами?` → `📢 Размещать рекламу у себя в аккаунте` / `❌ Только UGC (без размещения)` |
| Согласия | Текст с документами + кнопка «✅ Подтвердить согласие» |

### После регистрации
- **Полный текст:**  
  `Профиль создан 👍`  
  `Остался последний шаг — подтвердить Instagram‑аккаунт.`  
  `Это нужно, чтобы:`  
  `— защитить бренды от фейков`  
  `— повысить доверие к вашему профилю`  
  `— быстрее получать заказы`
- **Прервана регистрация:**  
  `Регистрация прервана. Чтобы завершить, откройте «Мой профиль» и подтвердите согласие.`
- **Сессия:**  
  `Сессия истекла. Начните заново.`

### Ошибки при вводе (креатор)
- `Выберите одну из кнопок: Мужской или Женский.`
- `Выберите: В основном женщины, мужчины или Примерно поровну.`
- `Укажите не более 3 городов через запятую.`
- `Введите число, например 500, 1000, 2000.`
- `Выберите Да или Нет.`

## 4. Профиль (Мой профиль / Редактирование)

### Заголовок
- `👤 Ваш профиль`

### Меню
- `Редактировать профиль`
- `👤 Мой профиль`
- `📂 Мои заказы`
- `💬 Поддержка`
- `Редактировать профиль блогера` / `Редактировать профиль рекламодателя`

### Подсказки при редактировании полей (блогер)
- Имя: `Введите новое имя:`
- Instagram: `Прикрепите ссылку instagram.com/name:`
- Город: `Из какого вы города?`
- Пол: `Укажите ваш пол:`
- Тематики: `Напишите 1–3 тематики через запятую:`
- Аудитория — пол: `Кто в основном смотрит ваш контент?`
- Аудитория — возраст: `Основной возраст вашей аудитории?`
- Аудитория — гео: `Укажите до 3 городов через запятую:`
- Цена: `Укажите цену за 1 UGC‑видео в рублях:`
- Бартер: `Готовы работать по бартеру?`
- Формат работы: `Как готовы работать с брендами?`

### Подсказки при редактировании полей (рекламодатель)
- Имя: `Введите имя:`
- Телефон: `Укажите номер телефона для связи. Пример: 89001110777`
- Бренд: `Название вашего бренда / компании / бизнеса:`
- Сайт: `Ссылка на сайт, продукт или соцсети бренда:`
- Для полей «Город», «Деятельность компании» при редактировании используется общий prompt: `Введите новое значение:`

### Кнопки выбора в профиле
- Пол: `Мужской`, `Женский`
- Аудитория: `👩 В основном женщины`, `👨 В основном мужчины`, `👥 Примерно поровну`
- Возраст: `до 18`, `18–24`, `25–34`, `35–44`, `45+`
- Бартер: `Да`, `Нет`

### Прочее
- `Выберите профиль для редактирования:`
- `Сессия истекла. Откройте «Мой профиль» снова.`
- `Не удалось обновить профиль.`

## 5. Верификация Instagram

### Сообщения
- **Профиль не заполнен:**  
  `Профиль не заполнен. «Создать профиль» или /creator`
- **Аккаунт уже подтверждён:**  
  `Ваш Instagram‑аккаунт уже подтвержден`
- **Инструкция (перед отправкой кода):**  
  `Чтобы подтвердить Instagram‑аккаунт, сделайте 3 шага:`  
  `1. Скопируйте код ниже`  
  `2. Отправьте его в личные сообщения Instagram‑аккаунту UMC`  
  `3. Дождитесь автоматического подтверждения`  
  Далее — ссылка на Instagram UMC (например https://www.instagram.com/usemycontent/)  
  `Ваш код (код действует 15 минут) 👇`
- **Код** отправляется отдельным сообщением в теге `<code>...</code>`.
- **Кнопка:** `✅ Подтвердить Instagram`

## 6. Создание заказа

### Вход
- **Нет профиля:**  
  `Профиль рекламодателя не заполнен. Команда: /advertiser`
- **Согласия не подтверждены:**  
  Текст с офертой/политикой/согласием + `Пожалуйста, подтвердите согласие с документами платформы.`
- **Старт:**  
  `Что вам нужно?`

### Тип заказа (кнопки)
- `🎥 UGC-видео для бренда`
- `📢 UGC + размещение у креатора`

### Шаги диалога
| Шаг | Что пишет бот |
|-----|----------------|
| Описание задачи | `Кратко опишите задачу для креаторов. Что снять и в каком формате. Пример: Видео с распаковкой.` |
| Формат сотрудничества | `Какой формат сотрудничества вам подходит?` → 🎁 Бартер / 💰 Оплата / 🔄 Бартер + оплата |
| Бюджет | `Бюджет за 1 UGC-видео? Укажите цену в рублях: 500, 1000, 2000` или `Введите число, например 1500.` |
| Бартер | `Что вы предлагаете по бартеру? Продукт бренда (опишите коротко) + доставка` |
| Количество креаторов | `Сколько креаторов вам нужно?` |
| Ссылка на продукт | `Введите ссылку на продукт (для откликнувшихся креаторов):` |
| Фото | `Прикрепите фото (по желанию). Фотография поможет креатору быстрее понять заказ и повысит отклик на ваше предложение` → кнопки: `📷 Добавить фото` / `⏭ Пропустить` или `Отправьте фото продукта:` |
| Использование контента | `Где вы планируете использовать UGC-видео?` → 📱 В соцсетях бренда / 📢 В рекламе (таргет, объявления) / 🔄 В соцсетях и рекламе |
| Сроки | `⏱ До 3 дней` / `⏱ До 7 дней` / `⏱ До 14 дней` |
| География | `В каких городах или регионах может находиться креатор? Можно указать от 1 до 10 городов, регионы или написать «РФ». Нужно для бартерных заказов и доставки продукта.` |

### Общие фразы
- `Выберите один из вариантов на клавиатуре.`
- `Сессия истекла. Начните заново с «Создать заказ».`

### После создания заказа
- **Успех (полный текст):**  
  `Заказ создан ✅`  
  `Мы отправим предложение подходящим UGC-креаторам после оплаты.`  
  `🔄 **Как это работает**`  
  `• Креаторы получают оффер с зафиксированными условиями`  
  `• Откликаются только те, кто готов работать на ваших условиях`  
  `• Вы получите отклики со ссылками на профили креаторов`  
  `• Связь начинается с вашей стороны`  
  `⚠️ **Важно**`  
  `• Оплату креатору рекомендуем производить после превью с водяным знаком`  
  `• Платформа не участвует в переговорах и оплате`  
  `• Мы не гарантируем, что креатор не изменит своё решение`  
  `• Креатор не видит ваши контакты и не может написать первым`
- **Нет цены:**  
  `Стоимость доступа не настроена. Свяжитесь с поддержкой.`

### Предупреждения (security_warnings) — полные тексты
- **Блогеру (безопасность сделки):**  
  `⚠️ **Безопасность сделки:**`  
  `• Не передавайте готовое видео до получения оплаты`  
  `• Рекомендуем отправлять превью с водяным знаком`  
  `• Оплата должна быть получена перед передачей финального контента`
- **Блогеру (помните о безопасности):**  
  `⚠️ **Помните о безопасности:**`  
  `• Не отправляйте готовое видео до оплаты`  
  `• Используйте превью с водяным знаком для демонстрации`  
  `• Получите оплату перед передачей финального контента`
- **Рекламодателю (порядок работы):**  
  `⚠️ **Безопасный порядок работы:**`  
  `• Платформа не рекомендует предоплату`  
  `• Оплачивайте после получения превью с водяным знаком`  
  `• Убедитесь в качестве контента перед финальной оплатой`
- **Рекламодателю (контакты с блогерами):**  
  `⚠️ **Безопасный порядок работы с блогерами:**`  
  `• Платформа не рекомендует предоплату`  
  `• Оплачивайте после получения превью с водяным знаком`  
  `• Убедитесь в качестве контента перед финальной оплатой`  
  `• Переговоры и сделки — напрямую между вами и блогером`
- **Рекламодателю (рекомендации по оплате):**  
  `⚠️ **Рекомендации по безопасности:**`  
  `• Оплата должна производиться после получения превью`  
  `• Не переводите полную сумму до проверки качества контента`  
  `• Используйте безопасные способы оплаты`

## 9. Оплата

### Сообщения
- `Некорректная сумма заказа.`
- `Сумма заказа слишком большая для выставления счета в Telegram.`
- Заголовок инвойса: `Оплата заказа`. Описание в инвойсе — текст оффера заказа (до 255 символов). Подпись позиции: `💳 Заплатить <N> ₽`. Описание для чека (54‑ФЗ): `Услуги платформы Use My Content`.
- `Не удалось создать счет. Попробуйте позже.`
- `Использование: /pay_order <order_id>`
- `Неверный формат order_id.`
- `Заказ не найден.`
- `Заказ не принадлежит рекламодателю.`
- `Заказ не в статусе NEW.`
- `Стоимость доступа не настроена. Свяжитесь с поддержкой.`
- `Платежный провайдер не настроен.`
- `Не удалось определить заказ.`
- `Пользователь не найден. Выберите роль через /role.`
- `Заблокированные пользователи не могут оплачивать заказы.`
- `Пользователи на паузе не могут оплачивать заказы.`

### После оплаты (рекламодатель) — полные тексты
- **Успех:**  
  `Оплата прошла успешно ✅`  
  `Подбор креаторов по вашему заказу активирован.`
- **Что дальше:**  
  `🔄 **Что дальше**`  
  `📩 Креаторы получают ваш оффер`  
  `🔗 Вы будете получать отклики со ссылками на их профили`  
  `💬 Вы самостоятельно связываетесь с выбранными креаторами`
- **Важно:**  
  `⚠️ **Важно**`  
  `🧷 Условия оффера не рекомендуется изменять после публикации`  
  `🔄 Если условия меняются, креатор может отказаться от сотрудничества`  
  `🤝 Платформа не является стороной сделки`

## 10. Обратная связь (feedback)

- `⏳ Ещё не связался`
- `⚠️ Проблема / подозрение на мошенничество`

### Причины «Не договорились» (блогер)

- `⏱ Не подошли сроки`
- `📝 Условия отличались от оффера`
- `🤝 Другое`

### Причины «Не договорились» (рекламодатель)
- `💰 Не сошлись по условиям`
- `⏱ Не подошли сроки`
- `📝 Креатор хотел изменить условия`
- `🤝 Другое`

### Вопрос при выборе «Не договорились»
- Блогеру: `Подскажите, по какой причине не удалось договориться?`
- Рекламодателю: `По какой причине не удалось договориться?`

### Описание проблемы (при выборе «Проблема / подозрение на мошенничество»)
- `Опишите проблему и приложите скриншоты переписки или другие подтверждения. Это поможет разобраться.`  
  `👉 Напишите текст, прикрепите фото и нажмите «Отправить».`

### Кнопки и короткие ответы
- `📤 Отправить` (для отправки описания проблемы)
- `Готово` (после NPS-комментария, когда не хотят писать)
- `Спасибо за обратную связь.`
- `Спасибо, ответ сохранен.`
- При выборе «Всё прошло нормально»: `Спасибо за обратную связь 👍 Если понадобится помощь — мы на связи.`

Сообщение блогеру: `Хорошо, вернёмся к этому позже 👍 Если заказчик напишет — просто ответьте ему.` Рекламодателю: `Поняли, вернёмся к этому позже 👍` `ℹ️ Креатор не видит контакты. Связь начинается с вашей стороны.`
- При достижении макс. переносов: `Достигнут максимум переносов. Статус зафиксирован как 'Не договорились'.`

- `Заблокированные не могут оставлять отзыв.` / `На паузе не могут оставлять отзыв.`
